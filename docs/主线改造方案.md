# 《南桥夜市》解谜主线改造方案

> 本文件是剧情设定的唯一依据，包含全部谜底、账号与密码。
> 仅供开发与评审使用：**不要在游戏页面中展示，也不要随作品提交包交给玩家**。
> 仓库为公开仓库，玩家可能从 GitHub 直接读到本文；若需要保密，提交前将本目录移出提交包，或把仓库转为私有。
> 与代码同步维护——改剧情时，本文件与 `src/data/*.json` 一并更新，两者不一致时以本文件为准，并回头把代码改到一致。

本分支为 v8（2026-11-09），基于 `main` 上 2026-11-07 发布的 v7。
v8：润色私信、手记、帖子、评价和公告。结局改为「线索／故事／后续」三页，第三页保留两条后续。
v5：ID 改为摊主=摊位号 / 管理处 M1 / 食客 C+数字。
v6：游客 ID 缩短为 C+5 位、聊天清空机制与追问链重做、结局改为四幕与抉择、开场加入失踪钩子。
v7：聊天时间统一到开市后、去掉未读与红点、陈伯手机清空规则定稿、手记不再提删聊天、视觉改版。

## 五、结局

1. **线索｜关门以后**。从邻摊替陈伯收凳子写起，接上缺班、钥匙、寻人启事、红绳和线路图。
2. **故事｜那碗粥是谁喝的**。交代陈念走失和被领养、陈伯认出红绳却不敢开口，以及他最后一次收摊后回到梧桐苑。
3. **后续｜把话捎给谁**。玩家收到陈念的私信，在同一页选择并看到后续。
   - 私信告诉他梧桐苑。王主任帮忙转号码，父子通了电话。五周年那晚，陈念在 A1 帮陈伯搅粥，邻摊送来吃的。
   - 请王主任先问陈伯。五周年那晚大家替陈伯留着摊位，他回了消息，让主任问陈念哪天歇班，有空来喝粥。

梧桐苑是线路图能够推出来的地点，结局只使用这个地点。两种选择都在剧情中处理私信，不写入玩家的本地论坛或短信。

**机制不变**：灯笼常驻导航栏（灰→点亮）、集齐 10 节点弹一次、未集齐硬闯显示"灯还没亮"。  
10 节点 = 帖子1/2/3 + 小李×刘姐 + 刘姐×陈伯 + 老张×陈伯 + 陈伯手记 + 儿子手记 + 寻人启事 + 地铁线路图。

## 六、功能与页面规则（现行）

- **登录**：ID 登录（摊位号 / M1 / C+数字；账号名兼容）；登录、切换账号无需刷新；注册自动分配 `C`+5位数字
- **短信页**：仿微信双栏（窄屏单栏）；会话按最新消息倒序；跨天处居中显示日期，气泡上不显示时刻；可发消息，自己的消息靠右、暖黄气泡；**不设未读角标、红点与未读标记**；无记录的会话显示「记录已清空」
- **论坛**：帖子与评论均按时间倒序；发言人 `名字 ID:xxx`；评论即时显示
- **商户导览**：按摊位号排列；`老板：xxx ID:yyy`
- **摊位**：可发布评价（即时显示）
- **长文本**：帖子/评论/评价/消息均保留换行
- **手记**：按时间从早到晚排列；支持 `**加粗**`；只读，不提供在线编辑
- **置顶公告**：特殊深红横幅，无日期、长期有效
- **排班表**：2026年10月整月日历，每天2人；陈伯周二/周日
- **开场**：新生来吃夜市 → 发现 A1 锁门 → 论坛有人问 → 决定查清楚
